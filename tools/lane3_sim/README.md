# 3차선 닫힌 고리 시뮬레이션

판단 코드(`three_lane.py`의 `ThreeLane`)가 낸 속도·조향으로 차를 움직이고, 그 결과로 다시 선·라이다를 만들어 넣는 시뮬레이션이다.
실차와 맞춰 본 적은 없다. 실차에서 깨진 배치가 여기서는 통과한 경우가 있었다 (NOTES.md 1번).

## 파일

| 파일 | 내용 |
|---|---|
| `sim5.py` | 본체. `load(path, **상수 덮어쓰기)`로 three_lane.py 를 읽고 `run(T, obstacles, ...)`으로 한 번 주행 |
| `sim6.py` | sim5 + 표지판을 "도로 가운데 근처에서, 일정 거리 간 뒤에만" 읽히게 (`read_half`, `read_m`) |
| `repro.py` | 11/15 실차에서 멈춰 섰던 배치 재현 (가운데 긴 장애물, 오른쪽 2개, 왼쪽 1개) |
| `e6.py` | 무작위 배치 생성 (`trials`) + 집계 |
| `e8.py` | repro 배치의 간격을 바꿔 가며 + e6 무작위 100개씩 |
| `e9.py` | 7대 완전 무작위 배치 (`seven`), 집계 함수 `evaluate` |
| `e10.py` | 7대를 4줄(2,2,2,1)로 놓는 배치 (`rows7`) |
| `e11.py` | e10 을 줄 간격 3종으로 40개씩 |
| `e16.py` | e10 줄 간격 1.0~1.2 m 한 세트만 (빠른 확인용, 약 2분) |
| `e13.py` | 왼쪽·가운데가 섬 앞까지 막혀 오른쪽으로 온 뒤 표지판 A |
| `e15.py` | sim6 사용. 오른쪽/왼쪽/가운데로 접근 × 표지판 A/B/못 읽음 (섬 앞 대기 로직 확인용) |
| `score.py` | **성적표**: 배치 200개 × 표지판 A/B = 400회. 완주·멈춤·접촉·섬·바깥선·갈림길 정답을 표로 (sim6 사용, 2코어 약 6분) |
| `meas_drive_log.py` | ~/simple_lane_log 의 log.csv 로 회전 반경·조향 지연·차로 폭을 잰 스크립트 |
| `three_lane_2c767b3.py` | 돌릴 때 쓴 판단 코드 (race 2c767b3 과 같은 내용) |

## 실행

numpy 만 있으면 된다 (three_lane.py 가 cv2 를 import 하므로 opencv 도 필요).

저장소에서는 이 폴더(tools/lane3_sim)에서 돌린다. 판단 코드는 `../../src/jetracer_ros2/jetracer_ros2/three_lane.py`.
(아래 예의 `three_lane_2c767b3.py` 는 원래 채팅방에서 쓰던 사본 이름이다. 저장소에는 넣지 않았다 = race 2c767b3 의 three_lane.py)

```
python3 score.py 옛=../../src/jetracer_ros2/jetracer_ros2/three_lane.py,PLANNER=old 새=../../src/jetracer_ros2/jetracer_ros2/three_lane.py --show 5
python3 repro.py three_lane_2c767b3.py
python3 e16.py 새=three_lane_2c767b3.py
python3 e11.py 새=three_lane_2c767b3.py
python3 e13.py 새=three_lane_2c767b3.py
python3 e15.py three_lane_2c767b3          # 확장자 없이
python3 e8.py 새=three_lane_2c767b3.py
```

상수를 바꿔 돌리려면 `sim5.load('three_lane.py', PATH_MARGIN=0.01, URGENT_BELOW=9.9)` 처럼 넘긴다.

## 가정

### 차
- 뒤 차축 기준 자전거 모델. 축거 0.20 m, 윤거 0.172 m, 회전 반경 = 0.20 / tan(조향) + 0.086 (25도에서 0.515 m).
- 조향은 1차 지연 (`lag`, 기본 0.15 s, 잡음 세트에서는 0.2~0.35 s). 속도는 명령 즉시 따라간다. 미끄러짐 없음.
- 차체(접촉 판정): 0.32 × 0.22 m, 가운데가 뒤 차축 앞 0.10 m.
- odom: 위치는 실제 속도를 odom 방향으로 적분, 방향은 실제 회전에 `yaw_err`(0.8~1.25)를 곱한 것.

### 센서
- 카메라 22 Hz, 라이다 10 Hz.
- 라이다: 250줄, -110도~+110도 (실차 기록과 같음), 거리 잡음 표준편차 1 cm, 8 m 넘으면 inf.
  라이다 위치는 뒤 차축 앞 `lidar` m (0.20 또는 0.10. 실차 값은 재지 않았다).
- 선: 직선 도로. 흰 선 ±0.27, 노란 선 ±0.80. 카메라 옆 거리 0.35 m 넘는 선은 1.25배 벌어져 보이게.
  옆 1.05 m 안의 선만 보이고, 먼 선은 10 % 확률로 빠진다. 차가 도로 방향에서 45도 넘게 틀면 선이 하나도 안 보인다.
  위치 잡음 `noise`(0.02 m, 30도 넘으면 2배), 한 프레임 통째로 안 보일 확률 `vis_drop`(0.3).
- 섬: 앞끝 XI, 반폭 0.27 m, 길이 3 m. 노란 테두리 점은 앞 0.4~1.9 m, 옆 1.0 m 안에서만 보인다.
  섬 1.9 m 안에서는 안쪽 흰 선이 노란 선으로 보이기 시작한다. 섬 앞끝 뒤 0.12 m 에 6 cm 기둥(표지판).
- 표지판: 틀리게 읽는 경우는 없다. sim5 는 섬까지 `d_sign` 안이면 바로 정답, sim6 는 가운데 근처에서 `read_m` 간 뒤 정답.

### 장애물
- 도로 방향으로 반듯한 직사각형. 정차 LIMO = 0.32 × 0.22 m, 옆 위치는 차로 정가운데 (e10 은 앞뒤 위치만 표준편차 4 cm 흔들림).
- e6: 길이 0.32~0.52, 폭 0.22~0.40 으로 무작위, 옆으로 표준편차 3 cm 흔들림. repro: 폭 0.22/0.30/0.40.
- e10: 4줄, 줄마다 한 차로만 열려 있고 열린 차로가 한 칸씩 옆으로 바뀐다. 섬은 마지막 줄 뒤 1.6~2.4 m.

### 넣지 않은 것
- 3차선 진입 전 곡선, 3차선 시작/끝 판단(`Lane3Supervisor`), 기본 주행으로 넘어간 뒤.
- 반사광·선 오검출, YOLO 오독, 라이다의 0.0 값(무효 표시)·빠짐, 비스듬히 놓인 장애물, 벽·사람.
- 계산 지연, 통신 지연.

## 결과 판정
- 통과: 섬 앞끝 + 0.8 m 까지 감 (`done`). 간 쪽: 섬 앞끝 + 0.5 m 에서 왼쪽이면 A.
- `minclr` ≤ 0 접촉, `island` > 0 섬 밟음, `out` > 0 바깥 노란 선 넘음.

## 주의
- 예전 버전(goal/sim4, tight/sim5)은 선 모델이 틀렸다 (`u = (pos - camy) / max(0.5, cos psi)`). 여기 있는 sim5 는 고친 것.
