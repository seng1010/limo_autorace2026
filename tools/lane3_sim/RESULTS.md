# 성적표 (score.py)

배치 200개 × 표지판 A/B = 400회. 배치·잡음·표지판 조건은 score.py 위쪽 설명 참고.
시뮬레이션이 실차 실패를 재현하지 못한 적이 있다 (NOTES.md 1번). 숫자는 옛/새 방식을 같은 조건에서 견주는 용도다.

- 완주: 섬 앞끝 + 0.8 m 까지 감. 멈춤: 70초 안에 못 감.
- 무결점: 완주 + 접촉 없음 + 섬 안 밟음 + 바깥선 안 넘음 + 표지판대로.
- "무작위 7대"는 3.1 m 안에 7대를 아무렇게나 놓은 것이라 실제 대회 배치보다 빡빡할 수 있다 (0.6 m 구간마다 한 차로만 비면 됨).
