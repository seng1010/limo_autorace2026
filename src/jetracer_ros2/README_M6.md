# M6 서행 유도선(지그재그)

> 작성: 성경수 · 브랜치 `m6_zigzag` (`fix-lane-curve` 기반) · **실차 미검증**
> 팀 원래 노드(`lane_following_node`)는 수정하지 않음

## 왜 만들었나
- 기존 코드는 지그재그를 감지해도 **속도만** 줄이고, 조향은 톱니를 그대로 따라감
- 시뮬레이션에서 지그재그가 화면을 채우면 차선 인식 실패 → **정지**

## 동작
1. **시작**: 지그재그 3프레임 연속 감지 → M6 모드 (0.15 m/s)
2. **주행**: 지그재그 선마다 직선을 맞춰 톱니를 무시하고 가운데로 직진
   - 차선 가운데 마름모·"천천히" 글자는 무시
   - 조향은 작고 부드럽게 제한
3. **끝** (먼저 오는 것)
   - 정지선 0.8m 이내 → `mission/event`로 `M6_DONE` 발행 (M3로 넘김)
   - 지그재그 5프레임 연속 안 보임 → 일반 주행 복귀

## 실행
```bash
ros2 run jetracer_ros2 lane_following_node_ks
```
- 기존 `lane_following_node`와 **동시 실행 금지**
- 상태 확인: `ros2 topic echo /lane/m6_state` (ARMED / ACTIVE / IDLE)
- 디버그 화면 아래쪽에 `M6 ACTIVE`, 초록 직선 표시

## 자주 바꿀 값 (`params.yaml`의 `m6_*`)
| 이름 | 기본 | 설명 |
|---|---|---|
| `m6_speed` | 0.15 | M6 속도 (규정 0.2 이하) |
| `m6_min_amplitude_ratio` | 0.03 | 지그재그를 못 잡으면 낮추기 |
| `m6_steer_gain` / `m6_max_steer` | 1.0 / 0.45 | 조향 세기 / 최대 조향 |
| `m6_require_mission` | false | true면 매니저가 M6일 때만 동작 |

※ 소수는 `0.15`처럼 소수점 포함, 정수는 `3`처럼 (형식 틀리면 노드가 안 켜짐)

## 테스트 (도면 치수로 만든 가짜 트랙)
- M6 없음: 지그재그 앞에서 정지 / M6 있음: 통과, 중심에서 최대 3~6cm
- 직선·코너·S자·점선·횡단보도에서 잘못 켜짐 0회
- `python3 -m pytest test/` → 30개 통과

## 실차에서 확인할 것
- 디버그 화면에 `M6 ACTIVE`가 뜨는지 (안 뜨면 `a=` 숫자 캡처)
- 정지선 노드가 "천천히" 글자를 정지선으로 착각하지 않는지
- 미션 연결(M5→M6→M3 자동 전환)은 아직 안 함
